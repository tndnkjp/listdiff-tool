# ListDiff - 2つの表（CSV）の差分比較マクロ

「変更前」「変更後」2つのCSVファイルを比較し、追加された行・削除された行・内容が変わった行を自動で判定し、一覧にまとめるExcel VBAツールです。
「名簿の突合をしたい」「価格表の更新箇所を確認したい」「在庫リストの差分を見たい」といった作業の自動化を想定しています。

## ダウンロード

**[⬇️ ListDiff.xlsm をダウンロード](https://github.com/tndnkjp/listdiff-tool/raw/main/ListDiff.xlsm)**

上のリンクをクリックするだけで、ブラウザが自動的にファイルをダウンロードします（gitの知識は不要です）。

## できること

- 「変更前」「変更後」2つのCSVファイルを比較
- 先頭列（1列目）をキーとして、同じキーを持つ行同士を比較
- 新しい方にだけある行を「追加」、古い方にだけある行を「削除」として判定
- 両方にあるが内容が変わっている行を「変更」として判定し、列ごとに「旧値 → 新値」の形式で表示
- 判定結果を色分け表示（追加=緑／削除=赤／変更=黄）
- 一度選んだファイルはブック内部に記録されるので、同じファイルのまま何度も比較し直す場合は選び直し不要

## 使い方

1. **[`ListDiff.xlsm` をダウンロード](https://github.com/tndnkjp/listdiff-tool/raw/main/ListDiff.xlsm)して開く**
2. 開いた際に以下のいずれかが表示されることがあります（出ない場合はそのまま手順3へ）
   - 黄色いセキュリティバー → 「コンテンツの有効化」をクリック
   - 赤い「セキュリティリスク」の警告（「このファイルのソースが信頼できないため、Microsoft によりマクロの実行がブロックされました」）→ 下記FAQ「ファイルを開くとマクロがブロックされて実行できない」を参照
3. 「**①変更前ファイルを開く**」ボタンで、比較元のCSVファイルを選ぶ
4. 「**②変更後ファイルを開く**」ボタンで、比較先のCSVファイルを選ぶ
5. 「**③比較実行**」ボタンをクリック
6. 「差分一覧」シートに、追加・削除・変更が一覧表示される

結果をリセットしたい場合は、「**結果シート削除**」ボタンを押してください。

これだけで使えます。VBAエディタを開く必要はありません。

## つまずきやすいポイント（FAQ）

### ファイルを開くとマクロがブロックされて実行できない

Excelの初期設定では、インターネット経由で取得したファイルのマクロは既定でブロックされます。症状としては主に次の2パターンがあります。

**パターン1：黄色いセキュリティバーが表示される**

「コンテンツの有効化」をクリックすれば使えます。

**パターン2：赤い「セキュリティリスク」の警告が表示され、「コンテンツの有効化」ボタンが出ない**

「このファイルのソースが信頼できないため、Microsoft によりマクロの実行がブロックされました」という表示です。これは最近のOfficeで追加された、より厳しいブロックで、Excelを開いたまま警告バーをクリックしても解除できません。**一度Excelを閉じてから**、以下の手順でブロックを解除してください。

1. ダウンロードした `ListDiff.xlsm` を右クリック → `プロパティ`
2. 「全般」タブの下部に「セキュリティ: このファイルは他のコンピューター上にあり、…」という注意書きと「許可する」チェックボックスがあるので、チェックを入れる
3. 「OK」で閉じる
4. あらためて `ListDiff.xlsm` を開く

それでも解消しない場合：`ファイル` → `オプション` → `セキュリティセンター` → `セキュリティセンターの設定` → `マクロの設定` で「警告を表示してすべてのマクロを無効にする」になっているか確認してください。

### 同じキーの行が複数ある場合はどうなる？

同じファイル内に同じキー（先頭列の値）を持つ行が複数ある場合、最初に出現した行のみを比較に使用します。2行目以降の内容は比較・出力に反映されません。該当するキーがあった場合は、「差分一覧」シートの5〜6行目に、重複していたキーと行番号が明記されます。

### 比較対象のデータがない場合はどうなる？

変更前・変更後いずれかのファイルに、比較対象となるデータ行が1件もない場合（ファイルが空、見出し行のみなど）は、「差分一覧」シートにその旨が明記され、判定処理は行われません。

### 「比較実行」のたびに前回の結果は消える？

はい。「③比較実行」を押すたびに「差分一覧」シートの内容は毎回全て書き換えられ、前回の結果は残りません。

## カスタマイズしたい場合

既定の設定を変えたい方向けに、VBAソースコードを `src/modListDiff.bas` として同梱しています。

1. `ListDiff.xlsm` を開き `Alt + F11` でVBEを開く
2. 左側のプロジェクトエクスプローラーで既存の `modListDiff` を右クリック →「解放」で削除
3. `ファイル` → `ファイルのインポート` から `src/modListDiff.bas` を選び直す
4. 冒頭の「設定セクション」の定数を書き換えて保存

| 定数 | 内容 |
|---|---|
| `INPUT_ENCODING` | 読み込むCSVファイルの文字コード |
| `HAS_HEADER` | CSVの1行目が見出し行かどうか |
| `DELIMITER` | CSVの区切り文字 |
| `OUTPUT_SHEET_NAME` | 差分を書き出すシート名 |
| `KEY_COLUMN_INDEX` | 「同じ行」と判定するためのキー列（1=先頭列） |

> `src/modListDiff.bas` はShift-JIS(CP932)で保存されています。テキストエディタで直接編集する場合、UTF-8で上書き保存すると、VBEへの再インポート時に日本語コメントが文字化けするのでご注意ください。
>
> 本ツールは、2つのファイルが同じ列構成（列の並び・意味）であることを前提にしています。

## 動作確認用サンプル

`sample_data/old_list.csv`（変更前）と `sample_data/new_list.csv`（変更後）を同梱しています。「①変更前ファイルを開く」「②変更後ファイルを開く」でそれぞれ指定し、「③比較実行」を押すと動作を確認できます。
